# Support XBRL views

## Outcome

Darty can retrieve evidence-backed XBRL views through stable, source-explicit
contracts.

## Current state

XBRL is in the broader product direction but has no accepted capability spec or
implementation. It remains intentionally unscheduled.

## Next action

Qualify DART's XBRL sources and decide the first stable capability boundary
after the Rust rewrite cutover.
