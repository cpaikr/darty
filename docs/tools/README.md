# Tool design guidance

This directory holds reusable design guidance for Darty capabilities. Product
scope belongs in [VISION.md](../../VISION.md), stable DART contracts in
[specs](../specs/README.md), and runnable evaluation instructions in
[evals](../../evals/README.md).

- [Foundations](foundations.md): capability boundaries and layering.
- [Contracts](contracts.md): semantic inputs, structured outputs, failures, and
  references.
- [Evaluation](evaluation.md): how deterministic tests, live checks, and
  scenario evals divide responsibility.

These documents describe principles, not a second product architecture or a
second source of operation-specific contract values.
