Usage: darty search-company-reports [options]

Return company-specific DART filings for an 8-digit DART company code. This
operation does not resolve company names; use search-company first when you need
companyCode lookup.

Options:
  --company-code <text>                      [required] 8-digit DART company code. Use search-company first if you only know a company name or stock code.
  --start-date <YYYYMMDD>                    [required] DART search period start date (YYYYMMDD). The search period is limited to 10 years.
  --end-date <YYYYMMDD>                      [required] DART search period end date (YYYYMMDD). The search period is limited to 10 years.
  --page <number>                            [default: 1] DART search result page, starting at 1.
  --page-size <number>                       [default: 15] Number of filings to request per page (15, 30, 50, 100; 5/10 normalize to 15).
  --sort-direction <asc|desc>                [default: desc] Receipt-date sort direction (asc or desc).
  --presenter-name <text>                    Narrow results by 제출인명 (presenter name).
  --report-name <text>                       Narrow results by 보고서명 (report title), for example 사업보고서. Use --disclosure-type for disclosure type codes.
  --disclosure-type <code>                   Add a 공시상세유형 detailed code. Repeat for multiple codes. Examples: A001(사업보고서), A002(반기보고서), A003(분기보고서), I001(수시공시).
  --industry-code <code>                     Narrow results by DART industry code. Default is all. Example: 612(전기 통신업). Use all if unknown.
  --corporation-type <all|P|A|N|E>           Narrow results by corporation type (all=전체, P=유가증권시장, A=코스닥시장, N=코넥스시장, E=기타법인).
  --closing-accounts-month <all|1-12|01-12>  Narrow results by fiscal closing month (all, 1-12, or 01-12). Values 1-9 normalize to 01-09.
  --include-all-reports                      Include pre-correction filings. Default behavior applies DART's final-report filter.
  --detail <concise|detailed|raw>            [default: concise] Source evidence detail level. evidence contains parser-check fields such as raw DART row text or snippet HTML. concise omits it; detailed/raw include it. raw still does not return full DART source HTML. Use --verbose with the CLI to see evidence.
  --pretty                                   Print human-readable indented JSON.
  --verbose                                  Include source evidence and diagnostic fields omitted from the default CLI output. If --detail is omitted, request detail=raw.
  --agent                                    Print compact agent-focused JSON with contextual next-step help.
  -h, --help                                 Display command help.

Examples:
  # Search recent company-specific filings with a verified DART company code.
  darty search-company-reports --company-code 00190321 --start-date 20250507 --end-date 20260507

  # Include pre-correction filings and request 30 results per page.
  darty search-company-reports --company-code 00190321 --start-date 20250507 --end-date 20260507 --page-size 30 --include-all-reports

  # Narrow company filings by disclosure type and report title.
  darty search-company-reports --company-code 00190321 --start-date 20250507 --end-date 20260507 --disclosure-type A001 --report-name 사업보고서

Search tips:
  - If you know the company name but not the company code, first run `darty search-company --company-name <company name>` to find the 8-digit companyCode.
  - The search period is limited to 10 years. Split longer ranges into windows of 10 years or less because DART can respond as if there are no results.
  - By default, DART's final-report filter is applied. `--include-all-reports` includes pre-correction filings and may increase the total count.
  - Use DART detailed disclosure type codes (A001=사업보고서, A002=반기보고서, A003=분기보고서, I001=수시공시, etc.). If you do not know a code, run `darty disclosure-types --query <term>`, and repeat `--disclosure-type` for multiple codes.
  - Fiscal closing month is sent as a DART month code (01-12). CLI input such as `--closing-accounts-month 1` is normalized to `01`.
  - Pass a result filing.receiptNumber or references.viewerUrl to `view-report` for follow-up retrieval.
  - Use `--detail detailed` or `--detail raw` with `--verbose` when you need source evidence such as raw DART row text. raw adds row-level evidence fields, not the full DART search HTML.
